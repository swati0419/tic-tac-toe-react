# Tic Tac Toe ❌⭕
A responsive Tic Tac Toe web application built using React and Context API for state management, styled with Tailwind CSS, featuring score tracking, winner detection, and interactive UI.

---

## ✨ Features

- 🎮 Interactive gameplay
- 👥 Two-player mode
- 🏆 Winner detection logic
- 🤝 Draw match detection
- ⚡ Instant UI updates
- 📱 Fully responsive design
- 🎨 Modern and clean interface
- 🔄 Restart game functionality
- 🧩 Component-based React architecture

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS 
- Vite
- JavaScript
